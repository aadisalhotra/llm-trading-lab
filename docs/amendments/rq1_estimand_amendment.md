## 1. Estimand (final text for the PRE_REGISTRATION.md RQ1 entry)

> **Estimand (amended).** RQ1's confirmatory estimand is the **null-adjusted excess concordance**: observed cross-model action concordance minus the mean concordance under the pre-registered permutation null, with the permutation p-value and confidence interval as the inferential apparatus. Raw concordance is not the estimand and is never reported alone. The permutation null independently shuffles, within each shared-input tick, each model's action vector across the tickers that model ruled on — preserving each model's per-tick BUY/SELL/HOLD composition while destroying cross-model ticker alignment. The null therefore represents the concordance expected from each model's per-tick action base rates — including any shared directional tilt across models — under random ticker assignment. The excess isolates **ticker-level decision convergence beyond shared per-tick action base rates: convergent security selection under identical information.** Because the models cannot observe one another and share only inputs, this is RQ1's herding construct, with social imitation excluded by design; the tilt component of shared-information response is deliberately netted into the null, so the estimand is specifically about *which securities*, not merely which direction.

## 2. Rationale — the pilot's worked example (June/July 2026)

> In June, observed concordance rose 0.596 → 0.909 — read raw, a dramatic herding surge. The permutation-null mean rose 0.471 → 0.903 over the same window, so the null-adjusted excess was **+0.006 (p = 0.156)**: the rise was driven by per-tick action compositions concentrating and directionally aligning across models — exactly what the null prices — with no increase in ticker-level selection agreement beyond random assignment given those compositions. Raw concordance would have reported a large false positive. In July, the excess was **+0.017 (p = 0.014)**: a small but significant ticker-level selection convergence beyond shared per-tick base rates, which raw concordance would have buried in compositional noise. The two months jointly demonstrate the estimand rejecting a spurious signal and detecting a real one — the complete case for null adjustment.

*Consistency check performed against the null's mechanics (not inherited from relay): under this null, expected pairwise agreement per ticker per tick is the composition overlap Σ_a p_A(a)·p_B(a), so the null rises iff per-tick compositions concentrate and align — June's lockstep null rise is that mechanism; July's excess is selection-level agreement the compositions cannot produce.*

## 3. Reporting rule (unchanged from ratified round two)

> Wherever RQ1 concordance is reported — the paper, monthly and quarterly reports, the dashboard — the observed concordance, the permutation-null mean, the excess, and the permutation p are reported **together**. Raw concordance never appears without its null. This rule is absolute because the June case shows exactly how a raw-only number misleads.

## 4. Two inferential mechanisms — named to prevent conflation

- **Permutation p:** generated by the within-tick, per-model ticker shuffle (§1) — the null distribution of concordance.
- **Confidence interval:** generated by the **moving-block bootstrap, 5-day blocks** (`research_metrics.py:341`, `DEFAULT_BLOCK_LENGTH = 5`) — temporal uncertainty of the excess.

These are separate mechanisms. The 5-day blocks belong to the CI, not the permutation. (The round-two text conflated them; the misdescription was session-carried and its origin is unestablished — the committed docstring has read correctly since file creation.)

## 5. Terminology (paper + September RQ1 review)

- The construct's precise name: **convergent security selection under identical information.**
- Introduce "herding" with this definition and the literature's taxonomy: Bikhchandani–Sharma distinguish *intentional* herding (imitation) from *spurious* herding (convergence on common information). The design isolates the spurious branch in its strictest form — even tilt-level common response (shared direction into a shared tick) is netted into the null, so the isolated quantity is selection-level convergence. The design constraint is a measurement advantage, and the definition preempts the "your design excludes herding" objection in the field's own vocabulary.
